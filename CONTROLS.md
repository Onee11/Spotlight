# ⌨️ OmniLaunch — Controls & Keyboard Shortcuts Guide

OmniLaunch is designed to be **100% keyboard-first**. You never need to touch your mouse to search, navigate, execute, or inspect files.

---

## ⚡ Global & Window Controls

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl + Space` *(Default)* | **Toggle Launcher** | Summon or hide the OmniLaunch search window from anywhere. *(Customizable in Settings)* |
| `Esc` | **Quick Dismiss** | Instantly hide the search window. |
| `Down Arrow` | **Next Result** | Move selection down through the search results list. |
| `Up Arrow` | **Previous Result** | Move selection up through the search results list. |
| `Enter` | **Execute** | Launch selected app, open file, copy math result, or open web search. |

---

## 📁 File & Result Quick Actions

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl + C` | **Copy File Path** | Copies the full file/item execution path of the highlighted result directly to your clipboard. |
| `Ctrl + Shift + Enter` | **Reveal in Explorer** | Opens Windows File Explorer with the selected file pre-highlighted in its containing folder. |

---

## 🔍 Search Triggers & Features

### 1. 🚀 Instant App Launcher
* Type any app name (e.g., `chrome`, `spotify`, `cmd`, `vlc`).
* OmniLaunch indexes your Start Menu and extracts native high-res icons.

### 2. 🧮 Inline Calculator
* Type any math expression directly into the search bar (e.g., `250 * 1.15`, `1024 / 8`, `(50 + 20) * 3`).
* Press **`Enter`** to instantly copy the calculation result to your clipboard!

### 3. 🌐 Web Search Triggers
* **Google Search**: Type `g <query>` or `google <query>` (e.g., `g WPF tutorial`).
* **YouTube Search**: Type `yt <query>` or `youtube <query>` (e.g., `yt C# .NET 9`).
* **Direct Web URL**: Type any URL (e.g., `https://github.com` or `www.google.com`) and hit **`Enter`**.

### 4. 📄 Hybrid File Search
* Type part of a file name or extension (e.g., `.png`, `.pdf`, `resume`, `invoice`).
* OmniLaunch performs a dual search across your **Desktop**, **Documents**, **Downloads**, and the **Windows Search Indexer**.

---

## ⚙️ Settings & Customization

* **System Tray Icon**: Right-click the OmniLaunch tray icon in the bottom-right taskbar to access **Settings...** or toggle **Start with Windows**.
* **Live Opacity Slider**: Adjust transparency between 40% and 100% with live visual feedback.
* **Key Recorder**: Click the hotkey box in Settings and press any custom key combination (e.g., `Alt + Space`, `Ctrl + Shift + K`) to rebind your trigger.
